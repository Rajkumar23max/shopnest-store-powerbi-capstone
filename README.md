Project Overview

ShopNest is an e-commerce marketplace operating across Portugal. This project focuses on analyzing store performance, customer behavior, order trends, and sales-related business metrics using Power BI.

Objectives

- Analyze e-commerce sales and order performance.
- Understand customer distribution and purchasing behavior.
- Explore trends across locations and product categories.
- Present business insights through interactive visualizations.

Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

Dashboard Features

- KPI cards for key business metrics
- Sales and order trend analysis
- Customer and geographic analysis
- Product performance analysis
- Interactive filters and slicers
